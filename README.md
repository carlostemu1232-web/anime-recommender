# 🎌 Anime Recommender

A Python anime recommendation application built with Tkinter and real anime data from the Jikan API.

## 🚀 Current Version

**v0.5**

The project currently connects to the Jikan API and uses the returned anime data to generate recommendations based on user preferences.

## ✨ Features

* 🌐 Real anime data from the Jikan API
* 🎭 Predefined anime genres
* 📺 Episode filters
* ⭐ Recommendations sorted by rating
* 🎌 Multiple anime recommendations
* 📜 Scrollable results
* 🖥️ Tkinter graphical interface
* ⚠️ Basic API error handling

## 🛠️ Technologies

* Python
* Tkinter
* Requests
* Jikan API

## ▶️ How to Run

Install the required dependency:

```bash
pip install requests
```

Then run:

```bash
python main.py
```
